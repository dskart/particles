✨ Particles

A shared particle simulation you play in your terminal over SSH.

1. Install websocat

SSH is tunneled over a WebSocket, so you need websocat.

brew install websocat

2. Connect

ssh -o ProxyCommand="websocat --binary {{.WSURL}}" particles

Or add this to ~/.ssh/config and run ssh particles:

Host particles
  ProxyCommand websocat --binary {{.WSURL}}

How to play

  • Click inside the box to drop particles in your color
  • Everyone connected shares the same world
  • Press Esc or Ctrl+C to quit
